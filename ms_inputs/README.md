# `ms_inputs/` — Gröbner-basis inputs

Each `.ms` file in here is an `f4ncgb` (msolve-format) input listing the
relations of a noncommutative ideal in the free algebra
$\mathbb{F}_p\langle x_1,\dots,x_{n-1},y_1,\dots,y_{n-1}\rangle$ or
$\mathbb{Q}\langle\cdot\rangle$.

## `qt_sweep/`

The ~230 specialised inputs feeding **Project A Phase 3** (multi-point
lift of the proof closure). Each file is the zipper algebra
$\mathcal{Z}_4$ presentation at one integer specialisation
$(q, t) = (q_0, t_0)$ over $\mathbb{Q}$, named
`zipper-n4-Q-q{q0}-t{t0}.ms`.

Generated by `tools/zipper_in_ms.py` and consumed by
`extract_cofactor_qt.py` and `reproduce_X3_zero.sh` in the project root.
The integer points are chosen to avoid the candidate denominator
vanishing loci $\{q=0, t=0, q-1=0, t-q=0, t+q^2=0, q+1=0\}$.

Two additional inputs in this folder:

- `zipper-n4-Q.ms` — unspecialised reference input.
- `zipper-n4-X3-Q.ms` — the same with $X_3$ appended as a target line
  (its trace gives the cofactor expression directly).

These files are not edited; they are re-emittable from
`tools/zipper_in_ms.py` with the appropriate `--q`, `--t`, `--char 0`
flags.
